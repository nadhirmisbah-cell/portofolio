Cooperative Website for Koperasi Desa Merah Putih Cileunyi Wetan

Role: Web Developer
Technology: HTML5, CSS3 (Flexbox & Grid), JavaScript (Vanilla)
Project Type: Academic Project

Project Summary

This project is the development of the profile website for Koperasi Desa Merah Putih Cileunyi Wetan as part of an academic assignment. The website is designed to present cooperative information digitally, in a structured and accessible manner, with a clean appearance and responsive design across various devices.

Development Goals

  • Provide an official web-based information media for the cooperative.
  • Structure content clearly and easily understood by the community.
  • Implement a simple, consistent, and functional interface design.

Challenges & Solutions

  • Responsive layout without framework — Using CSS Flexbox and Grid to maintain consistent appearance.
  • Structure of cooperative information — Dividing content into Profile, Goals, Principles, and Vision & Mission pages.
  • Performance of static pages — Using semantic HTML and JavaScript as needed to keep it lightweight.

Main Features

  • Cooperative Profile Page
  • Goals and Principles Page
  • Vision & Mission Page
  • Responsive Design for Various Devices

Result

An informative, responsive, and lightweight cooperative profile website, suitable for the needs of a village cooperative as a digital information media.
